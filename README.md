TaxPulse AI — Smart Accounting & Client Operations Platform

📋 Περιγραφή Έργου
Το TaxPulse AI είναι μια σύγχρονη, B2B Web & Mobile πλατφόρμα σχεδιασμένη ειδικά για ελληνικά λογιστικά γραφεία. Στόχος της είναι η πλήρης ψηφιοποίηση της διαχείρισης πελατών, ο αυτοματοποιημένος παρακολουθητής φορολογικών υποχρεώσεων (Tax Obligations Tracker) και η ενσωμάτωση τοπικής Τεχνητής Νοημοσύνης (Local AI Copilot) για την ασφαλή επεξεργασία ευαίσθητων δεδομένων χωρίς παραβίαση του GDPR.

🚀 Βασικά Χαρακτηριστικά (Key Features)
1. Διαχείριση Πελατών & Μητρώου (CRM)
Πλήρες Προφίλ Φυσικών & Νομικών Προσώπων: ΑΦΜ, ΔΟΥ, ΚΑΔ, Κατηγορία Βιβλίων (Α', Β', Γ'), εκπρόσωποι και στοιχεία επικοινωνίας.

Smart Search & Filters: Ταχεία αναζήτηση βάσει ΑΦΜ, επωνυμίας ή κατηγορίας δραστηριότητας.

2. Φορολογικό Ημερολόγιο & Σύστημα Ειδοποιήσεων
Tracking Υποχρεώσεων: Παρακολούθηση προθεσμιών για ΦΠΑ, Φόρο Εισοδήματος, ΑΠΔ, myDATA, ΓΕΜΗ κ.ά.

Status Workflow: Παρακολούθηση κατάστασης εργασιών σε πραγματικό χρόνο (Σε αναμονή δικαιολογητικών, Σε εξέλιξη, Υποβλήθηκε, Εκπρόθεσμο).

Automated Reminders: Αυτόματες ειδοποιήσεις (Email / Push Notifications) προς τους λογιστές και τους πελάτες πριν τη λήξη των προθεσμιών.

3. Privacy-First Local AI Copilot (μέσω Ollama)
100% GDPR Compliant: Επεξεργασία δεδομένων τοπικά (On-Premise / Edge) χωρίς αποστολή ευαίσθητων πληροφοριών σε εξωτερικά cloud APIs.

Smart Data Extraction: Αυτόματη αναγνώριση και εξαγωγή δομημένων δεδομένων (JSON) από σημειώσεις και αδόμητα κείμενα.

Automated Communication: Αυτόματη σύνταξη εξατομικευμένων emails υπενθύμισης προς πελάτες.

RAG Document Search: Δυνατότητα αναζήτησης και σύνοψης σε ανεβασμένα έγγραφα και φορολογικές εγκυκλίους.

🛠️ Τεχνολογική Αρχιτεκτονική (Tech Stack)
Frontend: React.js (TypeScript, Tailwind CSS, Lucide Icons, Axios).

Backend: Spring Boot 3 (Java 21, REST APIs, Spring Security με JWT & RBAC).

Database: PostgreSQL (Spring Data JPA, Flyway DB Migrations).

AI Subsystem: Local Ollama API (llama3.2 / qwen2.5-coder).

Containerization: Docker & Docker Compose.

🎯 Στόχος & Αξία (Value Proposition)
Το TaxPulse AI μειώνει το διοικητικό φόρτο του λογιστή, εξαλείφει τον κίνδυνο εκπρόθεσμων υποβολών και προσφέρει πλήρη έλεγχο και διαφάνεια στις καθημερινές εργασίες του γραφείου, διατηρώντας ταυτόχρονα το υψηλότερο επίπεδο ασφάλειας και ιδιωτικότητας δεδομένων.
